A Hero That Learns

A self-playing, self-learning roguelike dungeon crawler. The hero is powered by tabular Q-learning: watch it navigate deadly procedural rooms, evaluate action vectors, and become measurably smarter episode after episode.

Looking for the original web version? See charles-forsyth/DungeonMind. This repository is the native desktop Rust edition with multi-threaded training and Mesa OpenGL fallback.

The Mind of the Hero

Real-time telemetry peering directly into the agent's decision-making process.

🧠

Tabular Q-Learning

Full ε-greedy reinforcement learning with geometric decay. The state encodes surroundings, monster distance/direction buckets, HP, inventory keys, and stair proximity.

👁️

Concurrent Watch Mode

Training runs full speed in the background (50–100+ episodes/sec) while periodically streaming immutable policy snapshots to the 60 FPS showcase frontend.

💬

Thought Overlays

Watch real-time thought bubbles above the hero displaying chosen actions, estimated Q-values, and strategic rationale ("monster close: retreating", "heading for stairs").

🗺️

8 Procedural Floors

120×80 dungeon levels with torchlit corridors, locked doors with provably reachable keys, traps, healing shrines, and 13 D&D monster archetypes with d20 dice rolls.

📊

Live Telemetry Panels

Exposes real-time reward curves, moving averages, deepest floor reached, exploration decay, and a 13-action utility bar chart comparing discrete candidate actions.

📦

Portable & VM-Ready

Shipped with Mesa llvmpipe software OpenGL fallback (`opengl32.dll`) so the game runs seamlessly even inside GPU-less virtual machines or cloud sandboxes.
