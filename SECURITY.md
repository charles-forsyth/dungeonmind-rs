# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or unexpected memory safety concern in DungeonMind, please report it through private vulnerability reporting:

1. **GitHub Advisory**: Submit via the [Security Advisory page](https://github.com/charles-forsyth/dungeonmind-rs/security/advisories/new).
2. Alternatively, email **charles.forsyth@ucr.edu** with the subject `[SECURITY] DungeonMind Rust`.

### Scope
DungeonMind is a standalone local desktop application written in 100% safe Rust game simulation logic with Macroquad graphics. It makes no outbound network connections, requires no network ports, and manages no authentication tokens.
